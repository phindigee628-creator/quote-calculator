# Instant Quote Calculator (Learning Project)

A sample quote calculator for a made-up cleaning company called Sparkle Clean. It is **not a real business**.

**Live site:** (paste your link here)

**Built with:** HTML, CSS and JavaScript

**What it does:**
- The customer picks a clean, the size of the home, extras and how often.
- The price updates straight away, with a clear breakdown and a discount for regular cleans.
- A button sends the quote to WhatsApp.

**Skills shown:** forms, JavaScript maths, updating the page live, responsive design, and clean, organised code.

**Make it yours:** change the prices at the top of `script.js` to suit any small business.
